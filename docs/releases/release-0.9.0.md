## Til alle

| | |
|:---:|---|
| ![Venteliste](https://api.iconify.design/hugeicons:hourglass.svg?height=28&color=%23000000) | **Venteliste.** ![Frigivet](https://api.iconify.design/heroicons:arrow-up-tray.svg?height=20&color=%23000000) Frigiv virker som før: kan du ikke komme efter fristen, ryger din billet til salg, og bliver den solgt, slipper du for regningen. Nyt er køen: er alt udsolgt, skriver du dig på ventelisten. Én kø per billettype, først til mølle. Frigiver en nabo en billet af din type, er den din, og du får en mail. |
| ![Telefon](https://api.iconify.design/heroicons:device-phone-mobile.svg?height=28&color=%23000000) | **Appen på telefonen.** Nu kan den ligge på hjemmeskærmen som alle andre apps. Se boksen ovenfor. |
| ![Mine indstillinger](https://api.iconify.design/heroicons:cog-6-tooth.svg?height=28&color=%23000000) | **Mine indstillinger.** Tandhjulet på forsiden. Vil du slippe for mails? Slå dem fra under ![Notifikationer](https://api.iconify.design/heroicons:bell.svg?height=20&color=%23000000). Vælg også høj kontrast, farver til farveblinde ![Farvevalg](https://api.iconify.design/lucide:palette.svg?height=20&color=%23000000) eller større tekst ![Tekst](https://api.iconify.design/lucide:a-large-small.svg?height=20&color=%23000000). |
